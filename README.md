# Yandex Maps Photo Helper 0.1.3

Расширение добавляет на страницу Яндекс Карт собственную кнопку «Добавить фото».

## Как работает

1. Пользователь нажимает кнопку расширения «Добавить фото».
2. Выбирает одну или несколько фотографий.
3. Расширение находит штатную кнопку Яндекса «Добавить фото местности» и нажимает её.
4. После появления стандартного диалога Яндекса расширение передаёт выбранные файлы в его `input[type=file]`.
5. Дальнейшая проверка и публикация выполняются в интерфейсе Яндекса.

## Установка

1. Распаковать архив.
2. Открыть `chrome://extensions/`.
3. Включить режим разработчика.
4. Нажать «Загрузить распакованное расширение».
5. Выбрать папку расширения.
6. Обновить страницу Яндекс Карт.
