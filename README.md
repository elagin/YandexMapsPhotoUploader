# Yandex Maps Photo Uploader

Расширение для Google Chrome, упрощающее загрузку фотографий в Яндекс Карты.

## Как работает

1. Пользователь нажимает кнопку расширения «Добавить фото».
2. Выбирает одну или несколько фотографий.
3. Расширение автоматически передаёт фотографии в механизм загрузки Яндекс Карт.
4. Дальнейшая обработка и публикация выполняются средствами Яндекс Карт.

## Установка

1. Распаковать архив.
2. Открыть `chrome://extensions/`.
3. Включить режим разработчика.
4. Нажать «Загрузить распакованное расширение».
5. Выбрать папку расширения.
6. Обновить страницу Яндекс Карт.

## Ограничения

- Требуется авторизация в Яндекс.
- Расширение работает только на страницах Яндекс Карт.
